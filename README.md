# EnglishMC 英语口语模组

在 Minecraft 单人世界里练习美式英语。支持 Minecraft Java 版 **1.20.1**、Forge **47.4.20** 和 Windows x64。游戏使用 Java 17。

## 安装与使用

1. 将构建生成的 `englishmc-forge-1.20.1-1.0.0.jar` 放进该 Forge 实例的 `mods` 文件夹。
2. 从「单人游戏 → 创建世界 → 英语口语」打开开关，选择 **B1、B2 或雅思 7.0 训练**。默认间隔 5 分钟，可选 1–60 分钟。开关、难度和间隔保存在世界里。
3. 进入世界后等待第一题，或者按 **V** 提前出题。教练按「美式英文题目 → 中文翻译 → 美式英文示范回答 → 中文翻译」播报。界面显示双语文字。
4. 按 **V** 录音，等字幕显示「录音中」后开口。再按 **V** 提交，也可等计时结束自动提交。**J** 重播本题，按键可在「选项 → 控制」中修改。
5. 你的英文识别文本会出现在示范回答下方。回答未通过时原题会保留，可以看提示后继续重试。通过后可能出现同类追问或词汇跟读，其余时间按设置间隔开启新对话。

暂停、打开聊天或切到其他窗口时，录音会停止，回到游戏后可以重试。字幕在游戏 HUD 中，暂停菜单、聊天输入框和其他全屏界面打开时暂时收起。

## 题库与判定

初版有 **60 个场景、180 道双语对话题、180 条词汇跟读**。每个难度包含相同的 60 个场景，题目、示范和跟读内容分别编写，覆盖日常、餐饮、通勤、旅行、人际、购物、学校、工作、就医、租房、消费、社区和 Minecraft 等主题。

- **B1** 练习简短日常应答。
- **B2** 练习补充细节、解释理由和处理常见变化。
- **雅思 7.0 训练** 练习展开观点、举例和解释取舍。

可跟读示范，也可用自己的话作答。跟读按识别结果对齐词语，偏离示范时会提示可能要重练的词。自由回答按语境词组、信息量和必要的展开方式检查。识别误差可能导致重试，尤其是有背景音、重口音或使用题库未覆盖的表达时。此功能提供口语练习反馈，不给出正式雅思分数或音素级发音评分。

## 语音与隐私

双语播报使用 Windows 本地英语（美国）和中文（简体）语音，通过 Windows 默认扬声器播放。识别使用随模组打包的 Vosk 美式英语模型。麦克风音频和识别文本在内存处理，不上传、不写入存档，也不发到聊天频道。第一次启用时会在当前 Windows 用户的本地应用数据目录解压模型。

如果只有字幕，确认 Windows 已安装英语（美国）及中文（简体）语音包。无法录音时在 Windows 声音设置确认默认输入设备，并检查桌面应用的麦克风权限。建议用耳机，避免扬声器回声影响识别。

## 构建

```powershell
.\gradlew.bat build
```

首次构建从 Forge、Maven Central 和 Vosk 获取依赖，语音构建输入使用固定版本及 SHA-256 校验。最终 JAR 在 `build/libs/`。安装后练习无需联网。题库在 `src/main/resources/assets/englishmc/lessons/scenes.txt`，维护时为同一场景补齐三个难度。

`verifyPractice` 检查题库、难度覆盖、无重复抽题及反馈判定。也可用 `verifyPractice -PspeechSample=绝对路径` 对 16 kHz、16 位单声道 WAV 运行本地识别。第三方来源见 [第三方组件](THIRD_PARTY_NOTICES.md)。
